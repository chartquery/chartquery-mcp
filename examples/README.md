# Examples

Prompts to try once the server is installed:

- "Make a QR code for https://chartquery.com as a PNG."
- "How many ChartQuery credits do I have left?"

Inspect the tools without an AI client:

```sh
export CHARTQUERY_API_KEY="YOUR_API_KEY"
npx @modelcontextprotocol/inspector npx -y @chartquery/mcp
```
